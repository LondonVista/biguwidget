AGY
Sign in to Antigravity (AGY)
Enables Gemini and Claude & GPT usage monitoring
🔍 Auto-detect Token (Recommended)
If Antigravity CLI or IDE is installed, BigUwidget can read credentials from Linux Secret Service (secret-tool) or ~/.gemini.
🔑 Paste Access Token
Paste your Antigravity OAuth access token (starts with ya29...) or credential JSON.
🌐 Google Account Sign-in
Log in with the Google account you use for Antigravity in the embedded browser.
Updates automatically sync to the widget.
