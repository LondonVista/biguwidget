# BigUwidget 1.0.8 — Mac

This is the **native macOS** widget (not Electron). Copy this folder onto a Mac.

## Install

Double-click **Install.command**, or drag `BigUwidget.app` into `/Applications`.

Needs macOS 13+.

## Updates

In the widget: **Settings → Updates**

- **Prompt** (default) — asks when GitHub has a newer zip
- **Auto** — opens the new Mac zip from GitHub
- **Off** — never checks

Feed: [github.com/LondonVista/biguwidget/releases](https://github.com/LondonVista/biguwidget/releases)

## Rebuild from source

In the parent `BigUwidget` folder:

```bash
./build.sh
```
