Sign in to Claude (Anthropic)
Reads sign-in from Claude Code (terminal)
✨ No browser sign-in needed
BigUwidget reads your Claude Code sign-in and queries Anthropic for the same 5-hour and weekly limits shown at claude.ai → Settings → Usage.
If not signed in yet or expired, open Terminal and run:
claude /login
Claude Code refreshes the token on its own, so BigUwidget will never sign you out.
Updates automatically sync to the widget.
